# HU-007 – Cálculo de ley ponderada

- **Actividad:** A4. Calcular la ley ponderada de cada pila
- **Módulo:** Registro de Muestras

## Historia de usuario

Como responsable de control de calidad, quiero calcular automáticamente la ley ponderada de las muestras de cada pila, considerando el tonelaje que representan, para determinar su ley estimada.

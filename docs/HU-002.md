# HU-002 – Asociación de labores a pilas

- **Actividad:** A1. Crear polígonos y asociarlos a pilas y labores
- **Módulo:** Programa de Muestreo SIG

## Historia de usuario

Como responsable de SIG, quiero asociar las labores de origen a los polígonos creados, para mantener la trazabilidad del mineral que conforma cada pila.

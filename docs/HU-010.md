# HU-010 – Asignación de cargas a tolvas

- **Actividad:** A5. Registrar blending por pila y tolva
- **Módulo:** Registro de Blending

## Historia de usuario

Como operador de blending, quiero asociar las cantidades de mineral de cada pila con las tolvas correspondientes, para mantener la trazabilidad de la distribución programada.
